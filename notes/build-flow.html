研习录网站搭建流程

2026-07-21 项目记录

从零到上线的六个关键步骤，以及每一步踩过的坑与收获。

PROJECT · MY-AI-BLOG STATUS · ONLINE
01

搭建开发环境

START

安装编辑器、版本控制工具与 AI 编程助手，为后续开发做准备。

  • 安装 VS Code 作为代码编辑器
  • 配置 Git 与 GitHub 账号
  • 安装 Claude Code（ npm 方式 + PowerShell 执行策略）
  • 接入 Kimi API，调试到 k2.7-code 模型跑通
踩坑：TLS 版本不支持、ECONNREFUSED、401 鉴权失败、模型名称格式错误
02

确定方向与设计语言

DESIGN

从模糊的想法收敛到具体的网站定位与视觉风格。

  • 定位为「博客 + 简单评论区」的研习记录
  • 不做复杂注册系统，先保持简单
  • 视觉方向：雕塑感与未来科技感结合
  • 网站取名「研习录」
产出：纯 HTML 骨架页面，确认内容逻辑后再叠加样式
03

搭建网站基础结构

BUILD

用 HTML 搭骨架，用 CSS 做视觉，先结构后样式。

  • 首页 index.html 与笔记详情页
  • 全局样式 style.css
  • 深色背景 + 衬线字体 + 暗红点缀色
  • 极细分隔线与克制留白
成果：CSS 样式完成后的暗色首页效果
04

发布上线

DEPLOY

通过 Git 存档代码，用 GitHub Pages 获得公开网址。

  • git init / add / commit 存档
  • git push 推送到 GitHub 仓库
  • 开启 GitHub Pages 服务
  • 获得正式公开网址
里程碑：网站第一次能被互联网上任何人访问
05

加入评论互动功能

INTERACT

接入 Giscus，让老师能在笔记下直接留言点评。

  • 使用 Giscus 评论插件
  • 基于 GitHub Discussions 存储评论
  • 访客用 GitHub 账号登录即可留言
  • 无需额外注册系统
踩坑：本地 file:/// 访问会被 giscus.app 拒绝，必须通过正式 https 网址测试
06

功能完善：笔记分类

ORGANIZE

用标签归档笔记，简化导航，提升可查阅性。

  • 每篇笔记添加分类标签
  • 新增 categories.html 分类归档页
  • 首页与详情页显示对应标签
  • 砍掉「关于」页面，精简导航栏
最终形态：带分类标签、可评论、可归档的研习录首页

下一步

把示例内容替换成真实学习笔记；评估是否升级为多人可发帖的内部交流平台。
